# Bedrift-nettside-mal

Gjenbrukbar **Next.js + Tailwind**-mal for bedriftsnettsider (norsk marked).

## Formål

Dette repoet er en startmal du kan klone og tilpasse til ulike bedriftskunder. Målet er en enkel, modern 4-siders nettside (hjem, tjenester, om oss, kontakt) med felles konfigurasjon for bedriftsinfo.

## Stack

- [Next.js](https://nextjs.org/) (App Router) + TypeScript
- [Tailwind CSS](https://tailwindcss.com/)
- Norsk språk (`lang="nb"`) i layout

## Kom i gang

```bash
npm install
npm run dev
```

Åpne [http://localhost:3000](http://localhost:3000).

## Tilpasning

1. Oppdater `src/config/site.ts` med bedriftens navn, slagord og kontaktinfo.
2. Bygg ut sidene (hjem, tjenester, om oss, kontakt) etter behov.
3. Bytt ut logos, farger og innhold.
